# Security Policy

## Supported Versions

Security updates will always only be applied to the latest version of Watchtower.
As the software by default is set to auto-update if you use the `latest` tag, you will get these security updates automatically as soon as they are released.

## Reporting a Vulnerability

Critical vulnerabilities that might open up for external attacks should be reported via GitHub's private security advisory system:

1. Go to <https://github.com/todd2982/watchtower/security/advisories/new>
2. Fill in the vulnerability details
3. Click "Submit report"

This ensures the report is sent securely to the maintainers of this fork and allows for coordinated disclosure.

We'll always try to get back to you as swiftly as possible, but keep in mind that since this is a community project, we can't provide guarantees about response time.

Non-critical vulnerabilities may be reported as regular GitHub issues.
